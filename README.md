## Working With AI Tools

I use AI coding tools as part of my normal workflow, not as a shortcut around understanding the code. This lets me plan and ship both backend and frontend systems faster, while still reviewing and testing everything myself before it goes live.

**Building & coding**
`Cursor` `GitHub Copilot` `Google Antigravity` `Devin` — For implementation, I write out the requirements and a plan first, then let the agent do the heavy lifting. I review, test, and understand every change before merging it.

**Problem solving & architecture**
`Claude` `ChatGPT` `DeepSeek` `Kimi` — I use these to reason through system design, debug tricky logic, and compare different approaches rather than accepting the first answer.

**Research & staying current**
`Grok` `Perplexity` `NotebookLM` — For tracking new tools, frameworks, and techniques, and for going deeper on specific technical topics.

**Docs & learning**
`ChatGPT` `Gemini` `Notion` — For documentation, explaining unfamiliar concepts, and keeping project plans organized.

AI speeds up how fast I can build, but I still review, test, and validate everything before it ships — the judgment stays mine.
