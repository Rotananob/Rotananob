## Working With AI Tools

I build with AI coding tools as part of my normal workflow — not as a shortcut around understanding the code. This lets me plan and ship both backend and frontend systems faster, while I still review, test, and verify everything myself before it ships.

![Cursor](https://img.shields.io/badge/Cursor-000000?style=flat-square&logo=cursor&logoColor=white)

![Claude](https://img.shields.io/badge/Claude-D97757?style=flat-square&logo=claude&logoColor=white)
![ChatGPT](https://img.shields.io/badge/ChatGPT-412991?style=flat-square&logo=openai&logoColor=white)
![Gemini](https://img.shields.io/badge/Gemini-8E75B2?style=flat-square&logo=googlegemini&logoColor=white)
![Notion](https://img.shields.io/badge/Notion-000000?style=flat-square&logo=notion&logoColor=white)

**Building & coding** — `Cursor` `GitHub Copilot` `Google Antigravity` `Devin`
For implementation, I write out the requirements and a plan first, then let the agent do the heavy lifting. I review, test, and understand every change before merging it.

**Problem solving & architecture** — `Claude` `ChatGPT` `DeepSeek` `Kimi`
I use these to reason through system design, debug tricky logic, and compare different approaches rather than accepting the first answer.

**Research & staying current** — `Grok` `Perplexity` `NotebookLM`
For tracking new tools, frameworks, and techniques, and going deeper on specific technical topics.

**Docs & learning** — `ChatGPT` `Gemini` `Notion`
For documentation, explaining unfamiliar concepts, and keeping project plans organized.

AI speeds up how fast I can build — but the review, testing, and final judgment stay mine.
